# Femme Forms — сайт студии

React + Vite + JavaScript, без внешних UI-библиотек. Чистая компонентная структура,
все тексты и данные вынесены отдельно от разметки, чтобы их было легко менять.

## Запуск локально

```bash
cd femme-forms
npm install
npm run dev       # локальный сервер разработки
npm run build     # production-сборка в папку dist/
npm run preview   # локальный просмотр production-сборки
```

Node.js 18+ рекомендуется.

## Структура проекта

```
src/
  components/   переиспользуемые UI-блоки (Header, карточки, BookingFlow, Footer...)
  sections/     секции главной страницы (Hero, Services, Masters, Reviews...)
  data/         редактируемые данные — услуги, мастера, отзывы, акции
  App.jsx       сборка страницы из секций
  main.jsx      точка входа

public/
  images/       фотографии (см. public/images/README.txt какие имена файлов ожидаются)
  videos/       видео для героя (см. public/videos/README.txt)
```

## Куда что класть и менять

1. **Фотографии** — положите файлы в `public/images/` с именами из
   `public/images/README.txt` (услуги, мастера, "о студии", галерея). Если файла нет,
   на его месте автоматически появляется мягкая заглушка — сайт не ломается.
2. **Видео на главном экране** — `public/videos/hero-massage.mp4`. Пока файла нет,
   показывается плавный градиентный placeholder.
3. **Услуги и цены** — `src/data/services.js`. Каждая услуга — объект с `title`,
   `description`, `duration`, `price`, `image`.
4. **Мастера** — `src/data/masters.js`. Рейтинг и количество отзывов на сайте
   считаются автоматически из `reviews.js`, вручную их менять не нужно.
5. **Отзывы** — `src/data/reviews.js`. Формат: `{ id, master, name, date, rating, text }`.
   Реальные отзывы уже внесены и не должны изменяться по смыслу.
6. **Акции / popup** — `src/data/promotions.js`. Поле `enabled: true` включает показ
   popup на сайте (появляется через ~18 секунд или при попытке уйти со страницы,
   максимум один одновременно). Сейчас акция выключена (`enabled: false`) — она
   пример структуры, а не реальное предложение.
7. **Контакты** — Telegram, WhatsApp и адрес сейчас захардкожены в
   `src/components/Header.jsx`, `Footer.jsx`, `sections/CTA.jsx`, `sections/Contacts.jsx`.
   При желании их тоже можно вынести в отдельный `src/data/contacts.js`.

## Запись на сайте (booking flow)

`src/components/BookingFlow.jsx` — полноценный 6-шаговый flow (услуга → мастер → дата →
время → контакты → подтверждение), полностью на клиенте. Даты в календаре реальные
(прошлые дни заблокированы), но **время** — демонстрационный фиксированный список
(`DEMO_TIME_SLOTS`), а «Подтвердить запись» не отправляет данные ни в какую систему —
это специально, чтобы не создавать фальшивую реальную запись.

### Как подключить реальный backend / YCLIENTS

Точка входа для интеграции — функция `handleConfirm` в `BookingFlow.jsx`:

```js
const handleConfirm = () => {
  // Точка интеграции: здесь в будущем будет вызов реального API / YCLIENTS.
  // submitBooking({ service, master, date, time, contact })
  setConfirmed(true);
};
```

Когда появится реальный backend или интеграция с YCLIENTS (`https://n1215844.yclients.com`),
здесь нужно:
- заменить `DEMO_TIME_SLOTS` на загрузку реальных свободных слотов по выбранной дате/мастеру;
- в `handleConfirm` сделать реальный запрос на создание записи и обрабатывать ошибки/успех
  перед показом экрана подтверждения.

## Статическая версия (один HTML-файл, открывается двойным кликом)

Проект уже настроен для сборки в один самодостаточный `index.html`
(через `vite-plugin-singlefile`, см. `vite.config.js`):

```bash
npm install
npm run build
```

Результат — папка `dist-static/` с `index.html` (весь HTML/CSS/JS внутри одного файла)
и папками `images/`, `videos/` рядом с ним. Просто откройте `index.html` двойным
кликом — сервер не нужен. Для шрифтов Google Fonts нужен интернет, сама страница
работает локально.

## Стиль

Токены цвета, шрифтов и отступов — в `src/index.css` (`:root`). Шрифты: Cormorant
(заголовки) и Manrope (текст), оба поддерживают кириллицу, подключены через Google Fonts
в `index.html`.
